LEADer — an AI voice Assistant

FASTEST DEPLOYMENT
1. Put index.html in a folder.
2. Use Vercel Drop or import the folder/repository in Vercel.
3. No build command is required for this static HTML site.
4. For a Git workflow, push index.html to GitHub and import the repo into Vercel.

FUNCTIONALITY
The page includes responsive navigation, scroll reveal, counters, cursor parallax, animated voice UI, demo modal, form validation, and reduced-motion support.

PRODUCTION INTEGRATIONS
The contact form is front-end only. Connect it to Tally/HubSpot or a Vercel serverless endpoint to store leads. Connect the demo to Vapi/Retell/Bland for real voice calls.
